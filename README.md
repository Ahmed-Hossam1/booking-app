# 🚀 Booking App
A modern, feature-rich booking and explore activities application built with React 19, TypeScript, Vite, and Tailwind CSS 4. This project features a clean UI, robust state management, activity filtering, and a responsive design.

## ✨ Key Features
- 🔍 **Explore Activities**: Browse available activities and tours with dynamic filtering and sorting functionalities.
- 🏷️ **Categories**: Filter activities by specific categories to easily discover relevant content.
- 🌟 **Best Sellers**: Highlight popular and best-selling activities dynamically.
- 📊 **Sorting & Pagination**: Sort activities by recommended, price, or rating, and navigate through multiple pages seamlessly.
- 📱 **Responsive UI**: Beautifully designed layouts using Tailwind CSS 4, Flowbite, and Radix UI.
- 📝 **Modern Forms**: Form management and robust validation using react-hook-form.
- 🚀 **Fast Performance**: Powered by Vite and TanStack Query for optimal asynchronous state management and rapid data fetching.
- ℹ️ **Information Pages**: Dedicated About, FAQ, Contact, Privacy, and Terms pages for user support and transparency.

## 🛠️ Tech Stack
- **Framework**: React 19
- **Build Tool**: Vite
- **Language**: TypeScript
- **Routing**: React Router DOM v7
- **State Management**: TanStack Query
- **Styling**: Tailwind CSS 4 & Flowbite
- **Form Management**: react-hook-form
- **Icons**: Lucide React & React Icons
- **Components**: Shadcn UI & Radix UI

## 🚀 Getting Started
### Prerequisites
- **Node.js**: v20+ recommended

### Installation
Clone the repository:
```bash
git clone <repository-url>
cd booking-app
```

Install dependencies:
```bash
npm install
```

Run the Development Server:
```bash
npm run dev
```
Open `http://localhost:5173` with your browser.

## 📂 Project Structure
- `src/components`: UI components organized by layout and feature (navbar, footer, cards, etc.).
- `src/pages`: React Router page components (Home, Search, About, Contact, FAQ, Privacy, Terms, etc.).
- `src/interface`: TypeScript interfaces and type definitions for strong typing.
- `src/data`: Mock data and static configuration files.
- `public`: Static assets and images.
